```python
def read_knowledge_strict(path=None):
    """读知识库，**区分"读不出来"与"没有"**：返回 `(data, 原因)`，原因非空 = 不可信。

    为什么必须有这么一个函数：`load_knowledge()` 在任何读/解析失败时都返回
    `{"nodes": []}`，而调用方往往会**把它写回去** —— 于是"一次读失败"就等于
    "用户的全部积累被清空"。这条规则**只准有一份实现**（`jddelete` 与 `kbreuse` 都用它）。

    **只读**：不隔离、不改名、不写盘（坏文件原样留着，等用户或 `kb.absorb` 自己处理）。
    """
    p = path or knowledge_path()
    if not os.path.exists(p):
        return {"nodes": []}, ""
    try:
        with open(p, "r", encoding="utf-8") as f:
            data = json.load(f)
    except Exception as e:
        return {"nodes": []}, "知识库 `knowledge.json` 读不出来：%s" % e
    if not isinstance(data, dict) or not isinstance(data.get("nodes"), list):
        return {"nodes": []}, "知识库 `knowledge.json` 的结构不对（应当是含 `nodes` 列表的对象）"
    return data, ""
```

## Task 1.5: 把「读不出来 ≠ 空」**真正**收归一处（独立复查发现的真实数据丢失路径）

**为什么必须插在 Task 2 之前**：Task 1 只收归了 `jddelete` 那一份。独立质量复查发现全仓其实有 **4 份**
同一判据，其中 `kb._quarantine_corrupt_kb` 那一份**带着一条真实的数据丢失路径**，
而它跑在**每一次分析**里（`app.do_analyze` → `kb.absorb`）。

**已实测复现**（GBK 编码的 `knowledge.json`，本项目文档自己说过栽过 GBK）：

```
写坏前：214 字节，用户有 1 张卡「语音识别」
老判据：read_json→None；read_text→''（解码失败被兜成默认空串）
        ⇒ _quarantine_corrupt_kb() → True（判定"可以写盘"）
absorb 之后：用户那张卡**消失**，文件里只剩本次的 1 张卡；**没有任何 .corrupt- 备份**
```

**根因**：老判据用 `store.read_text(path, "").strip()` 判断"文件里有没有内容" ——
而非 UTF-8 文件**解码会失败并被兜成 `""`**，于是"有内容但读不出来"被误判成
"空文件，没有可丢的数据"。**修法必须是"看原始字节"**，绝不能看解码后的字符串。

### 先把"统一口径"定死（后面 9 个任务都依赖这个决定）

| 文件情形 | 读得出来吗<br>（`read_knowledge_strict`） | 能安全写盘吗<br>（`knowledge_safe_to_write`） |
|---|---|---|
| 不存在 | 能（空库，无原因） | **能**（没有可丢的数据） |
| 0 字节 / 纯空白 | **读不出来**（不是合法 JSON） | **能**（没有可丢的**字节**） |
| 合法空库 `{"nodes": []}` | 能 | 能 |
| 合法且有内容 | 能 | 能 |
| **非 UTF-8（GBK）** | **读不出来** | **不能**（有字节、却读不出来 → 必须先备份或放弃写盘） |
| 截断 / 坏 JSON（有字节） | 读不出来 | **不能** |

**两列为什么不一样（这不是矛盾，是两个不同的问题）**：
"读得出来吗"是**读**的问题；"能安全写盘吗"是**写**的问题，关键是"丢了会不会痛"。
0 字节的文件覆盖上去不会丢任何东西 → 可以写（也**不该**为它造一个垃圾备份）；
GBK 文件里有用户的整库 → **绝不能**写。

```python
def _has_content_bytes(path):
    """这个文件里有没有**可丢的字节**？

    ⚠️ **必须看原始字节**，绝不能用解码后的字符串：非 UTF-8 文件（比如被 GBK 写坏的
    `knowledge.json`）在 `read_text` 里解码会失败、并被兜成默认空串，于是
    "有内容但读不出来"被误判成"空文件，没有可丢的数据"。这正是本函数存在的唯一理由
    （实测：GBK 的库会被内存里的空库顶掉，用户的卡全没）。
    """
    try:
        with open(path, "rb") as f:
            return bool(f.read().strip())
    except OSError:
        return False


def knowledge_safe_to_write(path=None):
    """知识库当前是否可以**安全写盘**？返回 `(可写, 原因)`。

    可写 = **读得出来**，**或者**文件里根本没有可丢的内容（不存在 / 0 字节 / 纯空白）。
    其余（有字节、却读不出来）→ 不可写：调用方必须先备份或放弃本次写盘，
    **绝不能**把内存里那份（`load_knowledge()` 给的 `{"nodes": []}`）写回去。

    这是「读不出来 ≠ 空」这条规则**唯一**的实现（`kb` / `jobdup` / `身份迁移` 都用它）。
    注意它与 `read_knowledge_strict` 的分工不同：那个回答"读得出来吗"，
    这个回答"写上去会不会丢东西" —— 0 字节的文件读不出来，但写上去不丢任何东西。
    """
    p = path or knowledge_path()
    _data, err = read_knowledge_strict(p)
    if not err:
        return True, ""
    if not _has_content_bytes(p):
        return True, ""
    return False, err
```

```python
    """按**原始字节**读；文件不存在 → `None`（读失败**不**兜成空 —— 那正是数据丢失的来源）。

    ⚠️ **备份 / 回滚必须用它**，不能用 `read_text`：非 UTF-8 文件在 `read_text` 里解码失败
```

## Task 1.8: **简历快照**也按字节（复查推翻了我"简历安全"的说法）+ 补两处零覆盖

**先纠正一句话**：Task 1.7 之前我说过"`resumelib` 不是数据丢失路径、**你的简历是安全的**"。
那句话**只对了读路径**。独立复查发现**建快照**这一步是文本读，实测三种场景：

| 场景 | 实测结果 |
|---|---|
| ① 非 UTF-8 母版 + 记录**没有** `sha256`（老记录 / 人工改坏，`_kind_on_disk` 明确支持） | 判成 `latest` → `_write_content(snap, "")` 写出 **0 字节"假存档"**（且快照不可变）→ 随后母版文件被新版覆盖 → **原文没了**，而库里还记着 `mother_file` 指向那个空文件（**静默"留了档"**） |
| ② CRLF 母版（UTF-8、有 sha256） | 文本读把 CRLF 归一成 LF → 快照写成 LF，**与原文不逐字节相等** —— 而 `_write_content` 的 docstring 明确承诺"快照与母版原文是**逐字节**相等的" |
| ③ 非 UTF-8 母版 + 有 `sha256` | mismatch → **根本不写快照** → 母版原字节被覆盖后消失（这条至少 `read_version` 会如实报 missing，不撒谎） |

**主代理已独立验证关键两环**：`resumelib._kind_on_disk("", {"name":"母版"}, "latest")` → `"latest"`（无 sha256 时不判 mismatch）；
`store.read_text(<GBK 文件>, "")` → `""` 而 `store.content_bytes_present(<同一文件>)` → `True`。
另确认 `_write_content` 用 `newline=""`（**写侧本来就保真**）—— 所以洞**只在读侧**。

**关于用户真实数据（说准，别夸大）**：`data/profiles/default/resumes.json` 的 `rv_0001` **带 `sha256`**
（`ea5b4eb4…`，与母版文件指纹一致）。所以**场景 ① 不适用于他的数据**；
他真正的暴露面是**场景 ③**（母版文件一旦变成非 UTF-8，再新建同名子版本，原文就没了）。

**Files:** Modify `resumelib.py`、`jdid.py`（只改注释）；Test `tests/test_resumelib.py`、`tests/test_jdid.py`、`tests/test_jobdup.py`、`tests/test_store.py`

```python
"""阶段 E：**知识库优先复用** —— 报告要的知识点，先问本地知识库。

单一职责：给一个知识点，回答"库里有没有？是哪一张？能不能直接用？"，以及"该往库里补什么"。
**它不写盘**：真正的写回一律走 `app.do_analyze` 里已有的 `kb.absorb`
（那条路已经被测试盯得很牢，不另开一条）。

铁律：
  1. **不 import `knowledge`**（`knowledge` 反向依赖本模块提供的注入对象，成环）；
     它需要的东西（一个 `call(messages)->reply 文本` 函数）由调用方注入。
  2. **不做字面相似度匹配**（`difflib` / 编辑距离一律不引入）：实测错例明确
     （「风险识别」会被认成「语音识别」），而认错的形态是"报告里塞进另一个概念的内容
     且看不出来"——那正是本项目最不能出的错（spec §2、§5）。
  3. 读知识库**只读**，且必须区分"读不出来"与"没有"（`store.read_knowledge_strict`）。
"""

import re

import kb
import log
import store

# 一次模型判定最多带多少条库内条目；超了分块，分块后仍超 → 退回确定性匹配
# （少命中，但**绝不**悄悄截断清单然后假装判过）。

# ASCII 括号内容（`词错率（WER）` / `评测标准(Rubric)`）。**只认 ASCII 开头**：
# 中文括号是解释性补充（`响应延迟（首字延迟）`），当别名会让 `Case（案例）沉淀`
# 贡献出泛化的 `案例`，任何叫「案例」的节点都会误命中（spec §5）。
_ASCII_PAREN = re.compile(r"[（(]\s*([A-Za-z0-9][A-Za-z0-9 .,\-]*?)\s*[)）]")


def _paren_keys(term):
    """术语里 **ASCII** 括号内容的归一化键（`词错率（WER）` → `["wer"]`）。"""
    out = []
    for m in _ASCII_PAREN.finditer(str(term or "")):
        k = kb.normalize_id(m.group(1))
        if k and k not in out:
            out.append(k)
    return out


def _keys_of_term(term):
    """一个术语的全部查找键：去噪全名 + 每个 ASCII 括号内容（去重、保序）。

    **口径必须沿用 `kb.normalize_id`**（NFKC + 去标点空白 + 小写），不许另造一套 ——
    否则报告里的节点名与库里的卡片 id 会对不上（spec §5）。
    """
    out = []
    for k in [kb.normalize_id(term)] + _paren_keys(term):
        if k and k not in out:
            out.append(k)
    return out


def _card_completeness(card):
    """`(reusable, missing)`：够格复用 = **定义 + 通俗解释 + ≥1 条真实来源链接**。

    `timeline` **不参与够格判定**：它是锦上添花（缺了照样能复用，只是要补算），
    但会出现在 `missing` 里 —— 报告要知道"这条的时间线是不是本次补的"。
    """
    missing = []
    if not str((card or {}).get("definition") or "").strip():
        missing.append("definition")
    if not str((card or {}).get("plain_explanation") or "").strip():
        missing.append("plain_explanation")
    if not (card or {}).get("sources"):
        missing.append("sources")
    if not (card or {}).get("timeline"):
        missing.append("timeline")
    reusable = not any(m in ("definition", "plain_explanation", "sources") for m in missing)
    return reusable, missing
```

```python
class Index:
    """知识库的"名字 → 卡片"目录。一次分析建一次，之后**只读**。

    索引键有三类（spec §5）：卡片的 `normalize_id(term)`、它的 `aliases`、
    以及它 term 里 ASCII 括号的内容。三者任一命中即算命中。
    """

    def __init__(self, cards=None):
        self.cards = {}      # card_id -> card
        self.by_key = {}     # 查找键 -> card（先到先得）
        for c in (cards or []):
            if not isinstance(c, dict):
                continue
            cid = kb.normalize_id(c.get("term"))
            if not cid or cid in self.cards:
                continue
            self.cards[cid] = c
            keys = [cid] + [kb.normalize_id(a) for a in (c.get("aliases") or [])]
            keys += _paren_keys(c.get("term"))
            for k in keys:
                if k:
                    # 先到先得：同一把键被两张卡占着时保留第一张（顺序稳定，绝不随机）
                    self.by_key.setdefault(k, c)

    def __len__(self):
        return len(self.cards)

    def terms_for_judge(self):
        """喂给模型判定用的"库里已有什么"清单（只带 id / 名字 / 一行定义，省 token）。"""
        return [{"card_id": cid, "term": str(c.get("term") or ""),
                 "definition": str(c.get("definition") or "")[:40]}
                for cid, c in self.cards.items()]

    def lookup(self, term):
        """`(卡片 或 None, 怎么命中的)`。

        `matched_by` 的**精确定义**（别用"键等于全名"这种代理判断 —— 那会把
        "节点叫 `WER`、库里叫 `词错率（WER）`"错报成 `exact`）：
          * `exact`  —— **两边全名去噪后完全相同**（`normalize_id(term) == normalize_id(card.term)`）
          * `abbrev` —— 通过**任一侧**的 ASCII 括号缩写命中的（如节点 `WER` ↔ 库里 `词错率（WER）`）
          * `alias`  —— 通过卡片**记录过的** `aliases` 命中的
        """
        full = kb.normalize_id(term)
        node_parens = set(_paren_keys(term))
        for k in _keys_of_term(term):
            card = self.by_key.get(k)
            if card is None:
                continue
            card_full = kb.normalize_id((card or {}).get("term"))
            if full and full == card_full:
                return card, "exact"
            if k in node_parens or k in set(_paren_keys((card or {}).get("term"))):
                return card, "abbrev"
            return card, "alias"
        return None, ""


def build_index(cards=None):
    """建目录。`cards=None` 时从磁盘**严格只读**读知识库。

    返回 `(Index, 原因)`：原因非空 = 知识库读不出来。这时**不阻止分析**，
    只是这次全部走联网，并由调用方把原因如实带进报告标注（spec §9）。
    """
    if cards is not None:
        return Index(cards), ""
    data, err = store.read_knowledge_strict()
    if err:
        log.log_event("kbreuse.kb_unreadable", level="warn", error=err)
        return Index([]), err
    return Index(data.get("nodes") or []), ""
```

```python
# 从卡片整条复制到节点上的字段。**刻意不含 `related`**：
# 它的 `{id}` 指向**上一次分析**的节点（`store.slug`），复制到本次报告里就是断链
# （本次节点的 related 由模型为这个 JD 头脑风暴产生，指向的 id 都在本次报告里）。
_COPY_FIELDS = ("definition", "plain_explanation", "category", "sources", "timeline",
                "interview_questions", "state")
# `term` 单独处理（取规范名 + 记原写法），`layer` 取 min，`confidence` 按有无来源重算。


def _origin_of(card):
    """这张卡**最早**的 `from_jds` 条目 → `{"job_title","date"}`（报告标注用）。"""
    rows = [x for x in ((card or {}).get("from_jds") or []) if isinstance(x, dict)]
    if not rows:
        return {"job_title": "", "date": ""}
    first = min(rows, key=lambda x: str(x.get("date") or ""))
    return {"job_title": str(first.get("job_title") or ""), "date": str(first.get("date") or "")}


def _fill_from_card(node, card):
    """把库里那份**整条**覆盖到节点上，返回节点**原来的**写法（`term_original`）。

    三处刻意不动：
      * `node["id"]` —— 报告里的关联概念图按它连线，改它会打断 `related`；
      * `node["related"]` —— 见 `_COPY_FIELDS` 上面的注释；
      * `node["kb_reuse"]` —— 由调用方 `plan_nodes` 写（这里只管内容）。
    """
    original = str(node.get("term") or "")
    for k in _COPY_FIELDS:
        if k in card:
            v = card[k]
            node[k] = list(v) if isinstance(v, list) else v
    node["layer"] = min(int(node.get("layer") or 0), int(card.get("layer") or 0))
    node["confidence"] = "verified" if card.get("sources") else "ai-generated"
    node["term"] = str(card.get("term") or original)
    return original


def plan_nodes(nodes, index, call=None):
    """就地做"库优先"：确定性匹配 →（可选）模型判定 → 填充 → 统计。

    返回统计（报告标注与日志都用它），并把 `kb_reuse` 写在每个**命中**的节点上。
    `call` 是**已经绑好 cfg 的模型调用函数**（`call(messages) -> reply 文本`）；
    `call=None` = 只做确定性匹配（不花模型调用），这也是模型判定不可用时的降级形态。
    """
    nodes = list(nodes or [])
    stats = {"total": len(nodes), "matched": 0, "reusable": 0, "timeline_reused": 0,
             "enriched": 0, "searched": len(nodes), "knowledge_error": ""}
    idx = index if index is not None else Index([])
    if len(idx) == 0:
        return stats
    found = {}      # id(node) -> (card, matched_by)
    for n in nodes:
        card, how = idx.lookup(n.get("term"))
        if card is not None:
            found[id(n)] = (card, how)
    rest = [n for n in nodes if id(n) not in found]
    if call is not None and rest:
        pairs = judge(rest, idx, call)
        for n in rest:
            card = idx.cards.get(pairs.get(str(n.get("term") or "")))
            if card is not None:
                found[id(n)] = (card, "assisted")
    for n in nodes:
        hit = found.get(id(n))
        if hit is None:
            continue
        card, how = hit
        reusable, missing = _card_completeness(card)
        stats["matched"] += 1
        original = ""
        if reusable:
            original = _fill_from_card(n, card)
            stats["reusable"] += 1
            if card.get("timeline"):
                stats["timeline_reused"] += 1
        else:
            stats["enriched"] += 1
        n["kb_reuse"] = {
            "card_id": kb.normalize_id(card.get("term")),
            "card_term": str(card.get("term") or ""),
            # ⚠️ **只在名字真的不同时**才记原写法：同名时留空串。
            # 不能直接写 `original if reusable else ""` —— 那样同名也会把原名塞进去，
            # 报告里就会冒出一句多余的「JD 里写作 语音识别」。
            "term_original": (original if (reusable and original
                                           and original != str(card.get("term") or "")) else ""),
            "matched_by": how,
            "reusable": bool(reusable),
            "missing": list(missing),
            "got": ("all" if (reusable and card.get("timeline")) else
                    ("sources" if reusable else "")),
            "origin": _origin_of(card),
        }
    stats["searched"] = stats["total"] - stats["reusable"]
    return stats
```

```python
JUDGE_SYSTEM = """你是知识库管理员。下面给你两份清单：
A. 我的知识库里**已有**的条目（card_id + 术语 + 一行定义）
B. 新岗位需要、但名字没能直接对上的一些知识点（node + 术语 + 一行定义）

请判断：B 里每一条，是不是**就是** A 里的某一条（同一个概念的不同叫法）。

只输出 JSON：{"pairs":[{"node":"<B 里的 node 原文>","card_id":"<A 里的 card_id>"}]}

硬性要求：
- `card_id` **必须是 A 里出现过的原样字符串**；不确定就**不要输出这一对**
- **只输出你确信是同一个概念的**；宁可少配对，也不要猜
- 一个 `card_id` 最多被一条 `node` 认领
- 全部中文，字符串内部禁止英文双引号与裸换行"""


def _chunks(seq, size):
    for i in range(0, len(seq), size):
        yield seq[i:i + size]


def judge(nodes, index, call):
    """让模型判一次"这些知识点是不是库里已有的某个概念"。

    返回 `{节点 term 原文: card_id}`。**逐条校验**，任何可疑的一律丢弃：
      * `card_id` 必须真实存在于**这一批**库里（**不许发明概念**）；
      * `node` 必须是这次问过的节点；
      * **一张卡只认一条**（模型说两个不同名字都等于同一张卡时，多半认错了一个）；
      * 返回畸形 / 调用抛异常 → **一条都不用**（等同"没命中"），记日志。
    """
    nodes = list(nodes or [])
    terms = index.terms_for_judge() if index is not None else []
    if not terms or not nodes:
        return {}
    wanted = {}
    for n in nodes:
        wanted.setdefault(str(n.get("term") or ""), n)
    out = {}
    for chunk in _chunks(terms, MAX_JUDGE_TERMS):
        payload = {"A": chunk,
                   "B": [{"node": t, "term": t,
                          "definition": str((n.get("definition") or ""))[:40]}
                         for t, n in wanted.items()]}
        try:
            reply = call([{"role": "system", "content": JUDGE_SYSTEM},
                          {"role": "user", "content": json.dumps(payload, ensure_ascii=False)}])
            data = json.loads(reply) if isinstance(reply, str) else None
        except Exception as e:
            log.log_exc("kbreuse.judge_error", e)
            continue
        pairs = data.get("pairs") if isinstance(data, dict) else None
        if not isinstance(pairs, list):
            log.log_event("kbreuse.judge_bad_shape", level="warn",
                          got=type(pairs).__name__)
            continue
        allowed = {c["card_id"] for c in chunk}
        for p in pairs:
            if not isinstance(p, dict):
                continue
            node_term = str(p.get("node") or "")
            cid = str(p.get("card_id") or "")
            if node_term not in wanted or cid not in allowed:
                continue
            if cid in out.values():
                continue          # 一张卡只认一条
            out[node_term] = cid
    return out
```

```python
def build_for_jd(jd_text, cfg, core_limit=MAX_CORE, reuse=None, search=None, chat=None):
    """编排：① 拆解 → ② 头脑风暴 →（新增）库优先复用 → ③ 搜索 → ④ 时间线

    expanded = brainstorm(core, cfg, chat=chat)
    all_nodes = core + expanded
    stats = reuse.plan(all_nodes) if reuse is not None else None
    attach_sources(all_nodes, cfg.get("search_providers") or [],

                  verified=sum(1 for n in all_nodes if n["confidence"] == "verified"),
                  kb_reused=(stats or {}).get("reusable", 0),
                  kb_matched=(stats or {}).get("matched", 0))
```

```python
class Reuse:
    """生产用的薄包装：建一次目录、把模型调用绑好，然后 `plan(nodes)`。

    为什么要有这个类：`app.py` 需要"一个对象，拿着它调 `.plan(nodes)`"；
    模块级 `plan_nodes(nodes, index, call)` 参数多、且每次调用都要重建目录。
    """

    def __init__(self, index, call=None):
        self.index = index
        self.call = call
        self.last_stats = None
        self.knowledge_error = ""

    @classmethod
    def from_store(cls, call=None):
        """从磁盘建目录。**知识库读不出来也能造出对象**（原因记在 `.knowledge_error`）。"""
        index, err = build_index()
        obj = cls(index, call=call)
        obj.knowledge_error = err
        return obj

    def can_judge(self):
        return self.call is not None and len(self.index) > 0

    def plan(self, nodes):
        stats = plan_nodes(nodes, self.index, call=self.call)
        stats["knowledge_error"] = self.knowledge_error or stats.get("knowledge_error", "")
        self.last_stats = stats
        return stats
```

```python
class WriteBackSafetyTest(IsolatedCase):
    """够格复用写回后，那张卡**除了 `from_jds` 多一条、`last_seen` 更新，
    再按 `kb` 自己的两条规则变 `layer`（取 min）与 `related`/`interview_questions`（取并集）之外，
    逐字节不变**。

    这是本阶段的承重断言（spec §7 的不变量）：复用的内容是从卡片**原样复制**的，
    而 `kb._merge_into` 是"只增不减"，所以除上述几处之外前后对比必须一致。
    谁把实现写歪（比如覆盖了你的掌握度），这条就会红。

    ⚠️ **订正（2026-10-15 收尾轮）**：初稿写的是"**除了 `from_jds` 与 `last_seen` 之外**
    逐字节不变"，并把 `related`/`layer` 也归进"不许变" —— **那条要求不可能成立**
    （`related` 的并集每次都会发生、`layer` 取 min 会被拉低；两者都是 `kb` 自己的规则，
    与复用无关）。所以夹具**必须**取等值 `layer` + 空 `related`，这个前提写进本 docstring；
    仓库里最终那两条用例（`test_the_layer_is_the_kb_minimum_rule_not_a_reuse_side_effect`
    与 `test_related_is_unioned_by_the_kb_rule_and_the_reuse_side_copies_none`）
    把这两条规则**显式钉住**，不再靠夹具绕开。
    """

    JD = {"id": "新岗位", "job_title": "语音数据质检", "company": "", "date": "2026-10-15"}

    def _full_card(self):
        return {"id": "语音识别", "term": "语音识别", "definition": "库里的定义",
                "plain_explanation": "库里的通俗", "category": "核心概念", "layer": 0,
                "sources": [{"title": "维基", "url": "https://w"}],
                "timeline": [{"year": "2010", "text": "库里的时间线"}],
                "related": [{"id": "x", "relation": "相关"}],
                "interview_questions": ["会怎么问"],
                "state": "已掌握", "last_outcome": "已面试", "asked_count": 2,
                "review_count": 3, "last_reviewed_at": "2026-10-01", "last_result": "答上了",
                "from_jds": [{"id": "老岗位", "job_title": "老岗位", "company": "",
                              "date": "2026-10-03"}]}

    def _node(self, term="语音识别"):
        return {"id": "n1", "term": term, "definition": "本次定义",
                "plain_explanation": "本次通俗", "category": "核心概念", "layer": 0,
                "sources": [], "timeline": [], "related": [], "interview_questions": [],
                "confidence": "ai-generated", "state": "待学习"}

    def test_reuse_writeback_changes_only_the_refs_and_last_seen(self):
        store.save_knowledge({"nodes": [self._full_card()]})
        before = json.loads(json.dumps(store.load_knowledge()["nodes"][0]))

        node = self._node()
        kbreuse.plan_nodes([node], kbreuse.Index(store.load_knowledge()["nodes"]))
        kb.absorb([node], self.JD)

        nodes = store.load_knowledge()["nodes"]
        self.assertEqual(len(nodes), 1, "不许新建重复卡")
        after = nodes[0]
        # ⚠️ 订正（2026-10-15）：`layer` 与 `related` 也要排除 —— 它们是 `kb` **自己**的合并规则
        #    （layer 取 min、related 取并集），不是复用造成的；初稿只排除 from_jds/last_seen
        #    是因为夹具取了等值 layer + 空 related（那条路走不到），这里把前提写明。
        for k in sorted(set(before) | set(after)):
            if k in ("from_jds", "last_seen", "layer", "related", "interview_questions"):
                continue
            self.assertEqual(after.get(k), before.get(k), "字段 %s 被写回改了" % k)
        self.assertEqual(len(after["from_jds"]), 2, "本次岗位要记进来源岗位（spec 决策 6）")
        for k in ("state", "last_outcome", "asked_count", "review_count",
                  "last_reviewed_at", "last_result"):
            self.assertEqual(after[k], before[k], "用户进度字段 %s 不许被改" % k)

    def test_an_incomplete_card_is_completed_in_place_without_a_duplicate(self):
        """命中但不够格：联网搜到的来源**并进那张已有卡**（这就是"扩展完善已有知识点"）。"""
        card = self._full_card()
        card["sources"] = []
        card["timeline"] = []
        store.save_knowledge({"nodes": [card]})
        node = self._node()
        stats = kbreuse.plan_nodes([node], kbreuse.Index(store.load_knowledge()["nodes"]))
        self.assertEqual(stats["enriched"], 1)
        # 模拟 ③④ 联网之后拿到的东西（形状与生产一致）
        node["sources"] = [{"title": "新来源", "url": "https://new"}]
        node["timeline"] = [{"year": "2024", "text": "本次补算"}]
        kb.absorb([node], self.JD)
        nodes = store.load_knowledge()["nodes"]
        self.assertEqual(len(nodes), 1, "不许新建重复卡（身份对齐）")
        self.assertTrue(nodes[0]["sources"], "搜到的来源必须并进那张已有卡")
        self.assertEqual(len(nodes[0]["timeline"]), 1, "补算的时间线要写进去")

    def test_a_name_mismatch_would_create_a_duplicate(self):
        """**反向证据**：如果身份没对齐（名字还是「ASR」），写回就会新建第二张卡。

        这条测试的价值在于：它证明了"身份对齐"不是装饰 —— 少了它确实会多出重复卡。
        """
        store.save_knowledge({"nodes": [self._full_card()]})
        node = self._node("ASR")
        node["term"] = "ASR"          # 刻意绕过 `plan_nodes` 的对齐
        node["sources"] = [{"title": "T", "url": "https://t"}]
        kb.absorb([node], self.JD)
        terms = sorted(n["term"] for n in store.load_knowledge()["nodes"])
        self.assertEqual(terms, ["ASR", "语音识别"],
                         "夹具前提：不对齐就会多一张卡（这正是对齐要防的）")
```
