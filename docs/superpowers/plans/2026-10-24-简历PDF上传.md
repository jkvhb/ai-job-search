## 关键实现约束（写代码时不许忘）

1. **绝不出 `\uFFFD`**：映射不出来就记 warning 并跳过；整份都映射不出来 → `PdfError`。
2. **绝不猜版面**：只重建"换行 + 西文空格"，分栏可能串行（文档与界面都要说明）。
3. **所有上限都要真的生效**：单流 8 MB / 总解压 64 MB / 对象 2 万 / 页 50 / 深度 32 / 输出 200 万字符。
4. **失败一律人话**：`PdfError` 消息要能指导用户下一步（另存为 `.md` / 去密码 / 压缩）。
5. **只读**：`pdftext` 不碰磁盘；路由不写盘（只有用户点「保存」才走 `create_version`）。
