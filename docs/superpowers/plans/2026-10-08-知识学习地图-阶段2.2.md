# 知识学习地图 · 阶段 2.2 实现计划（列表位置记忆 + 搜索领域约束）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development。

**Goal:**
1. **列表视图记住位置** —— 点开某个知识点再返回列表时，滚动位置保持不变，并高亮上次打开的那一条（现在每次都要重新翻到底部）
2. **搜索必须限定在本领域** —— 现在的查询是 `"{term} 是什么"`，**搜回来的结果不做任何校验**，导致歧义术语搜到完全无关的内容（例：知识点「省略恢复」的来源出现「Microsoft 的撤销回复操作」）。要对结果做**本领域校验 + 相关性过滤**，**并给搜索次数设上限以节省 Tavily 额度**
   > ⚠️ **修正（见文末 Task 2.3）**：一开始以为要"给查询加领域锚定"，**实测证明那是错的**（会把术语冲掉，产出"领域对但跟术语无关"的来源，且能绕过过滤器伪装成可信来源）。最终方案是**查询保持裸术语 + 过滤做唯一护栏**。

**Architecture:** 任务 1 是纯前端（改 `web/report_template.html`，复用报告已有的 `state` 持久化）；任务 2 在后端 `knowledge.py`（查询构造 + 结果过滤 + 数量上限），并新增配置项便于调参。

**背景（用户原话）：** "点击最后一个知识点，跳转到【卡片视图】以后再回来又要重新翻到底部太麻烦了"；"仅仅是查到了字段相关，但并非AI领域…这是绝对不可以出现的，而且这会浪费大量的搜索tavily额度"。

新增常量与两个纯函数：

```python
# 本工具专做 AI 领域岗位；搜索必须锚定领域，否则歧义术语会搜到完全无关的内容
DOMAIN_TAG = "大模型 AI"

# 结果必须命中其一，才算"本领域来源"；否则丢弃（宁可不给来源，也不给错来源）
DOMAIN_KEYWORDS = (
    "ai", "人工智能", "大模型", "语言模型", "llm", "机器学习", "深度学习",
    "神经网络", "模型", "训练", "微调", "标注", "数据集", "语料", "评测",
    "算法", "语音", "对话", "推理", "prompt", "token", "智能", "生成",
)
```

```python
def build_query(node):
    """把术语锚定到本领域后再搜，避免歧义词跑偏"""
    term = (node.get("term") or "").strip()
    return ("%s %s" % (term, DOMAIN_TAG)).strip()


def filter_relevant(sources):
    """只保留命中领域关键词的结果——宁可无来源，也不给错来源"""
    keep = []
    for s in (sources or []):
        if not isinstance(s, dict):
            continue
        blob = ((s.get("title") or "") + " " + (s.get("snippet") or "")).lower()
        if any(k in blob for k in DOMAIN_KEYWORDS):
            keep.append(s)
    return keep
```

class SearchQualityTest(_Isolated):
    def test_build_query_anchors_domain(self):
        q = knowledge.build_query({"term": "省略恢复"})
        self.assertIn("省略恢复", q)
        self.assertIn(knowledge.DOMAIN_TAG, q)

    def test_filter_drops_off_domain_results(self):
        raw = [{"title": "Microsoft 撤销回复操作说明", "url": "https://ms", "snippet": "如何撤销回复"},
               {"title": "大模型数据标注中的省略恢复", "url": "https://ai", "snippet": "在语音对话数据里补齐省略成分"}]
        kept = knowledge.filter_relevant(raw)

        self.assertEqual(kept[0]["url"], "https://ai")

    def test_filter_keeps_empty_as_empty(self):
        self.assertEqual(knowledge.filter_relevant([]), [])

    def test_attach_sources_marks_ai_generated_when_all_filtered_out(self):
        def only_off_domain(query, providers=None, **kw):
            return [{"title": "Microsoft 撤销回复", "url": "https://ms", "snippet": "撤销操作指南"}]

        nodes = [knowledge.normalize_node({"id": "a", "term": "省略恢复", "definition": "d",
                                           "plain_explanation": "p"})]
        out = knowledge.attach_sources(nodes, [{"name": "t", "base_url": "u", "api_key": "k"}],
                                       search=only_off_domain)
        self.assertEqual(out[0]["confidence"], "ai-generated")
        self.assertEqual(out[0]["sources"], [])

    def test_attach_sources_respects_max_searches(self):
        calls = []

        def counting(query, providers=None, **kw):
            calls.append(query)
            return [{"title": "大模型 A", "url": "https://a", "snippet": "模型"}]

        nodes = [{"id": "n%d" % i, "term": "T%d" % i, "definition": "d", "plain_explanation": "p",

                  "layer": 1 if i >= 2 else 0} for i in range(5)]

# 阶段 2.2 修正（Task 2.3）：`build_query` 的领域锚定是错的，必须撤销

> **本节推翻了上面 Task 2 的核心假设。原因是实验数据，不是偏好。**

## 实验证据（5 个真实术语 × 4 种写法，20 次真实搜索）

用语料里的真实术语实测，指标 =「既切题（字面含术语）又属本领域」的结果数：

| 术语 | A `{t} 是什么` | B `{t} 大模型 AI` | C `"{t}" 是什么` | D `"{t}" 大模型 AI` |
|---|---|---|---|---|
| 省略恢复 | 3/3 | **0/3** | 3/3 | 0/3 |
| 裁决权限 | 0/3 | 0/3 | 0/3 | 0/3 |
| 抽样检验 | 1/3 | **0/3** | 1/3 | 0/3 |
| Transformer 架构 | 3/3 | 2/3 | 3/3 | 2/3 |
| 幻觉 | 1/3 | **3/3** | 1/3 | 3/3 |
| **合计** | **8/15** | 5/15 | **8/15** | 5/15 |

三条结论：
1. **引号毫无作用**：C ≡ A、D ≡ B **逐条结果完全相同**。唯一变量是"是否带 `大模型 AI`"。
2. **`大模型 AI` 把"可检测的错"换成"不可检测的错"**：B 会返回「15款大模型透明度测评」「视觉模型推进图像复原」这类**领域正确但跟术语无关**的页面。
   而 `filter_relevant` **只验领域、不验切题**——这些页面会顺利通过过滤并被标成**「有来源」**，
   比原来那条 Microsoft 的错更危险（伪装成可信来源）。
3. 只有「幻觉」一个术语上 B 更好（3/3 vs 1/3）。

补充验证（3 次搜索）：策略 E `{术语} + {定义前20字}` = 2/9，**比 A 更差**，放弃。
所有"带领域语境"的写法（V1/V2/Q1/Q2/E）都会冲淡术语，**不存在好的领域锚定查询**。
