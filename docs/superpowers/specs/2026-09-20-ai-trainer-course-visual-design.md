# AI 训练师课程 · 第1天 可视化自学材料 — 设计文档

## 目标
把飞书文档《AI 训练师课程内容》（第 1 天）制作成小学生也能听懂的高度可视化自学材料。

## 产出
- `学习材料/AI训练师课程-第1天-可视化自学.html`：自包含交互式学习页（推荐主用）
- `学习材料/AI训练师课程-第1天-演示版.pptx`：12 页演示文稿（适合讲解/分享）
- `学习材料/原文整理-飞书文档.md`：从飞书 SSR HTML 提取的原文

## 设计决策
1. 形式：HTML 为主（零依赖、动画、交互、可打印 PDF），PPT 为辅（python-pptx 生成）。
2. 结构：学习地图 → 来且曼的目的 → 12 名词卡片墙 → AIGC → 随堂小测验（8 题即时判分）。
3. 通俗化：每个术语配「一句话定义 + 小学生版 + 生活例子 + 动画迷你图」。
4. 动画：CSS/SVG 实现（流动线条、步伐动画），不使用 GIF，体积小且清晰。
5. 配色：深色底 + 每术语专属强调色，卡片式布局，移动端响应式。

## 内容扩展（基于原文）
- 原文：术语一句话定义 → 扩展：小学生版比喻、生活例子、四类 AIGC 内容、金句解读。
- 原文：优质数据=内容 → 扩展：AI 训练师工作价值链条（数据→训练师→模型→内容）。

## 验证
- Edge headless 渲染 DOM：12 卡片 / 8 测验 / 32 选项 / 12 SVG 全部正常。
- PPTX 通过 python-pptx 重新打开校验（12 页）。
