## 2026-09-19 · 模型接入踩坑（三连）
- 类型：`问题`
1. 模型名错误：`deepseek-v4-flash` 不存在（接口实际只有 `deepseek-flash`/`deepseek-v4-pro`）；`moonshot-kimi-k2.6` 错（实际 `kimi-k2.6`）
2. `temperature` 被 Kimi 拒（只接受 1）→ 改为可配置 + 自动降级重试
3. deepseek-flash 返回的 JSON 有语法错误（字符串内未转义英文双引号）→ 提示词加固 + 解析失败自动让模型修复
