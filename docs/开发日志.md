## 2026-10-08 · 阶段 2：力导向知识图谱
- 类型：`功能`
- 报告「知识学习地图」模块新增「🗺 关系总览」切换：canvas 手绘力导向图，零依赖离线可用
- 节点=知识点（颜色按核心/扩展分层），描边按置信度（绿=有真实来源 / 琥珀=AI整理待查证），琥珀外圈=当前卡片
- 交互：拖拽节点、滚轮缩放、拖背景平移、悬停高亮关联边、点节点跳回对应卡片
- 力模拟收敛后自动停止 rAF 循环省 CPU，拖拽时唤醒
- 悬空 `related` 引用只跳过边不报错；`KNOW` 为空 / 只有 1 个节点均不崩
- 踩坑：`window` 上的 `mousemove`/`mouseup` 每次进图谱态都重新注册会成对泄漏 → 用 `window.__kgBound` 只注册一次，并让监听体通过 `kG.canvas` 取当前 canvas（闭包捕获的那张重绘后已废弃）
- 踩坑：拖拽节点后浏览器仍会补发 `click`，导致一拖就跳卡片 → 用「本次按下后是否真的拖动过」过滤
