# AI 求职助手（本地工具 + SOP 提示词包）

面向 **AI 领域社招**（数据标注、AI 数据运营、标注管理、AI 产品经理等）的求职工具：
**粘贴 JD / 上传截图 → 自动跑 SOP → 生成一份交互式 HTML 分析报告**，并把简历与报告都存在本机。

## 它能做什么

1. 岗位预筛（硬门槛一票否决）
2. 岗位匹配打分（0–100，权重可调）
3. JD 结构化拆解 + 能力缺口识别
4. 简历撰写大纲 + 重点体现清单 + BOSS 打招呼话术
5. **简历优化方向**（增 / 删 / 改 / 量化补强 / 关键词对齐 / 逐段改写要点）
6. 面试准备（预测题 + 答案骨架 + 反问）
7. 投递 Checklist + 投递状态追踪

## 快速开始（本地工具，推荐）

1. **双击桌面上的「AI求职助手」图标**（快捷方式已放好，指向 `启动.bat`）
   - 也可以直接双击本目录的 `启动.bat`，或命令行 `python app.py`
2. 浏览器自动打开 **http://127.0.0.1:8000**
3. 首次使用：进「⚙️ 设置」填两个 API Key（模型名已内置正确值，通常不用改）
   - 文本分析：`deepseek-flash`（DeepSeek）
   - 识图 OCR：`kimi-k2.6`（Kimi / Moonshot）
4. 回到「① 分析岗位」：粘贴 JD / 上传截图 / 填分享链接 → 选简历 → 点「🚀 开始分析」
5. 报告存到 `reports/`，岗位信息自动写入 `data/jobs.json` 台账

> **注意**：同时只能开一个窗口。重复启动会提示「端口已被占用」。

> **没有 API Key 也想先看效果？** 点「看看示例效果（免 API Key）」即可生成一份内置示例报告。

## 输出形式（交互式 HTML）

文件命名：`reports/YYYYMMDD_岗位名_匹配分分.html`

固定 **7 个模块**：★ 岗位信息与联系方式 / 硬门槛判定 / 匹配打分 / JD 拆解·能力缺口 / 简历大纲 / **简历优化方向** / 面试准备

顶部有**可点击目录**（吸顶、滚动高亮），点章节名直接跳转；每个模块有独立主题色。

内置 **5 项交互**：
- ✅ 勾选清单（硬门槛确认、投递 Checklist、面试题"已准备"）
- 📂 可折叠答案（点开才显示面试答案骨架）
- 🎚️ 打分滑块（拖动即实时重算总分）
- 📊 投递状态可编辑（状态 + 下一跟进日期 + 备注）
- 📤 导出 PDF（一键打印）

勾选与打分状态存在本机浏览器（localStorage），报告文件本身永久保存在 `reports/`。

## 另外两种用法（不装工具也能用）

### 方式一：任意 Agent 环境
把本目录给 Claude Code / Cursor / DeepSeek Harness 等 agent，让它按 `00-求职SOP总纲.md` 的流程跑，结果同样按 HTML 规范落盘。

### 方式二：纯聊天框
ChatGPT / DeepSeek 网页版 / 微信 AI 等无写文件能力的聊天框：把对应流程文件的提示词 + 你的简历 + JD 粘进去，输出完整报告后自行保存。
